Rename to Choom

rename mine to Choom

Approach

  • Change only what you see: app and mascot name, window and tray titles, program and installer names.
  • Give Choom its own app ID so it installs separately and never mixes settings with an official Coucou.
  • Leave internal code names alone. Fewer edited lines means fewer clashes when upstream updates arrive.

Improvement

  • Keep every Choom string in one small file, so the rename survives any upstream update.
  • The internal relay, pipe and data folder keep their Coucou names, so your existing Claude Code hooks keep working with no reinstall.

Watch out

  • Uninstall Coucou before installing Choom. Both use the same relay, so running the two at once makes them fight over it.

Chat with your OpenCode key

use my OpenCode key in Choom's chat instead of a Claude API key

Approach

  • Your OpenCode Go key works directly. Go offers an endpoint in the same format Choom's chat already speaks (Anthropic Messages).
  • Step 1: add a setting for the chat address and model, pointed at OpenCode Go with Qwen3.8 Flash or MiniMax M3. Very little new code.
  • Step 2: add the OpenAI-style format too, which unlocks DeepSeek, Kimi and GLM on the same key.
  • The key goes in Windows Credential Manager like the Claude key does today, never in a file.

Improvement

  • A model picker on the chat header, filled from OpenCode's live model list.
  • For reference: a Claude API key comes from console.anthropic.com and is billed per use, separate from any Claude subscription. You don't need one.

Now playing

integrate Spotify to show the current song

Approach

  • Read Windows' own media controls (the panel that appears when you press a volume key) instead of Spotify's web API.
  • No Spotify login or developer account needed. You get title, artist, cover art, position and play, pause, skip.
  • It reacts to change events instead of checking every second, so Choom stays at zero CPU while hidden.

Improvement

  • It works for any player: Spotify, YouTube in Edge or Chrome, Apple Music, VLC. Choom follows whichever one is playing.
  • The compact pill shows cover art and a small equaliser. Hover for controls without opening the island.

Skip

  • Spotify's web API: it needs an app registration and an online login, and it only covers Spotify.

Synced lyrics

lyrics playback

Approach

  • Fetch time-stamped lyrics from LRCLIB, a free, open lyrics database with no key, matched by title, artist and song length.
  • Follow the song position from the media controls and highlight the current line.
  • Save fetched lyrics on disk, so a song only downloads once and works offline after that.

Improvement

  • Live lyric in the compact pill: the current line replaces the song title while the island is closed.
  • A timing nudge (plus or minus half a second) for players that report their position late.
  • Plain lyrics when no timed version exists, and a quiet "no lyrics" state instead of an error.

Limit

  • Spotify's own lyrics (from Musixmatch) aren't available to outside apps. LRCLIB covers most popular songs but not all.

Hover to wake

launch when it's not visible by hovering at the top middle of the screen

Good news

  • This already exists. While hidden, Choom keeps an invisible strip, 240 by 6 pixels, at the top centre. Touching it brings the island down.

Improvement

  • A short dwell (about 150 ms) so grabbing a browser tab or title bar doesn't trigger it by accident.
  • Ignore the strip while a mouse button is held, for example while dragging a window.
  • Stay hidden during full-screen games and videos. Windows can tell an app when that's happening.
  • A setting for strip width, and "Launch at startup" (already in Settings) so Choom is always running.

OpenCode as an agent pill

connect to OpenCode / OpenChamber

Approach

  • Coucou already accepts events from any agent that calls its relay with --agent <name>.
  • A small OpenCode plugin forwards session events (working, finished, needs permission) to that relay, so OpenCode gets its own pill next to Claude Code.
  • OpenChamber keeps working unchanged. It drives the same OpenCode server, so sessions you start there show up too.

Improvement

  • Second step: Allow and Deny cards for OpenCode permission requests, the same cards Claude Code gets today.

Notifications as a dynamic pill

make it the default notification app

Approach

  • Windows won't let another app replace its notification centre. Choom can read every notification with your permission and show it as the pill.
  • Then switch off Windows' pop-up banners (Settings, System, Notifications). Choom becomes the banner, and the notification centre still keeps the history.
  • Catch: Windows only grants this permission to apps with a registered identity. Choom needs a small signed "identity package". Do a one-day test first to prove it works.

Improvement

  • VIP apps: only apps you choose can drop the island. The rest collect quietly as a count.
  • Auto-quiet during full-screen apps and screen sharing.
  • One shared priority ladder so everything competing for the pill behaves predictably:
1Agent permission requests (they block your work)
2VIP notifications, shown for 4 seconds
3Agents working or just finished
4Now playing and live lyric
5Idle Choom

Staying update-friendly

New features live in their own folders (windows/src/choom/ and windows/src-tauri/src/choom/). Upstream files only get small hook-in lines, so update-coucou.ps1 keeps merging cleanly.

Who builds what

I design and review every phase. The bigger ones (2, 3, 6) can go to DeepSeek through OpenCode to save cost. You see each brief and approve it before it starts.

House rules kept

Keys stay in Credential Manager, zero CPU while hidden, Claude settings never edited without a backup and your click.
